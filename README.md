# Backend OTP Telegram

Deploy folder ini sebagai Node Web Service di Render. Setelah mendapat URL HTTPS, set di browser website:

```js
localStorage.setItem('divtelegramApi', 'https://URL-BACKEND-KAMU')
```

Lalu reload website. API ID, API Hash, nomor, kode OTP, dan password 2FA tidak boleh dikirim lewat chat.
